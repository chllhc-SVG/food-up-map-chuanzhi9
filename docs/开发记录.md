# 双城版本的开发记录

选手在对话中确定「美食UP主的榜单推荐——基于定位的个性化美食地图微工具」这个正式名称，并指定武汉原项目和福州作者主页。选手说已登录内置浏览器。下列工程决定和验证由助手执行，为过程索引；本次聊天可供核对完整上下文。

- 武汉版本沿用已有采集成果，导入时剔除长简介和无关参数，逐点核对 326 处坐标。两个视频指向同一门店时，门店只在列表中出现一次。
- 福州投稿接口未能完成匿名读取；助手改用选手登录的主页，在「投稿」页核对 8 页中的标题、日期和 BV 号，未读取或保存账号凭据。首页同时展示「最近点赞的视频」，导入边界选为作者投稿页，结果为 293 个不同的 BV 号。外地投稿留在视频目录。地点需另行查证。
- 离线点位图首版测试发现联网底图故障回退时的地图回调异常，改为等待当前事件处理结束再销毁地图。另一次点击测试发现选中点遮住聚合点，于是将同点店铺合并为可展开的标记。
- 本人位于外地、拒绝定位以及店铺只有街区参考坐标时，不能一律按精确距离排序。改版让用户可手选出发点，展示坐标精度和排序依据。探店标题存在负面意见时，不把它作为正向推荐理由。
- 新视频线索先核 BV 号并与选定作者的快照比对。店名命中只是候选；可保留待核，人工复核内容留在个人浏览器。这些新增要求是助手在开发和审查中提出的工程决定。
- 福州作者有一条原片同时点名「厚千禧汉堡」和「CARPORT咖啡」，另一期提到前者闭店。抽查发现，若用合辑标题给每个店打口味标签，搜汉堡也可能把咖啡店当作推荐结果。现将合辑标题保留在视频搜索中，店铺口味匹配只采用能归到单店的文本。用「厚千禧汉堡」做过浏览器复查，可以搜回原片并看到闭店提示。
- 福州的裕莲茶楼有两期投稿。首店的政府资料能把一期探店定位到东百中心 C 馆，另一期只能确认品牌。复核时分别记录分店证据和品牌线索。离线地图另用真实河流帮助辨认方位，河线的裁剪、简化和许可写入 `geography-sources.md`。

选手本人提出的需求、助手给子任务的工程指令以及用户实际试用意见，应分别保留原始记录。本文件不代替选手亲自完成的核心功能迭代或真实用户测试。
